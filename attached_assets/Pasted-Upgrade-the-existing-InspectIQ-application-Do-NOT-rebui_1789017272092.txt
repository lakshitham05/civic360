Upgrade the existing InspectIQ application. Do NOT rebuild the project from scratch and do NOT remove the existing working Report Issue functionality.

The goal is to make InspectIQ a unified multi-department inspection, complaint monitoring and resolution platform suitable for a Tamil Nadu government/public-service style hackathon prototype.

CORE CONCEPT:

Citizen reports a public problem → Department/category is identified → Inspector receives it → Inspection is performed → Risk/severity is assessed → Suitable team is recommended → Work is assigned → Citizen tracks the progress → Issue is resolved → Citizen provides feedback.
