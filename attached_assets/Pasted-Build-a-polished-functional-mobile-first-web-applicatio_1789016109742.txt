Build a polished, functional, mobile-first web application called **InspectIQ**.

### PROJECT

InspectIQ is a multipurpose AI-assisted inspection, monitoring, and work-allocation platform.

The application supports six domains:

1. 🏫 School
2. 🎓 College
3. 🏗️ Construction
4. 💡 Street Light
5. 🚰 Drainage
6. 🛣️ Road Safety

The application must be software-only. Do NOT use Arduino, ESP32, Raspberry Pi, physical sensors, IoT devices, or hardware.

### CRITICAL ARCHITECTURE

Do NOT create six separate applications.

Create ONE reusable application where the selected category dynamically changes:

* dashboard title
* issue types
* inspection checklist
* AI analysis categories
* risk calculation
* recommended worker/team type
* sample data
* reports

After login, the user selects a category.

For the selected category, provide THREE role-based dashboards:

1. USER / CITIZEN DASHBOARD
2. INSPECTOR DASHBOARD
3. ALLOCATION & MONITORING DASHBOARD

The same dashboard components must be reusable across all six categories.
